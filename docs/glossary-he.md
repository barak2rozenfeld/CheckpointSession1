# מילון מונחים דו-לשוני - Session 1 + Session 2

רשימה מהירה של מושגי שיווק/עסקים ומושגי סייבר שמופיעים בשתי המצגות, עם תרגום ומשמעות בשורה אחת. המטרה: שיהיה לך קל להבין ולהגיד.

- **Session 1** = ה-business case הפנימי (שוק, תחרות, SWOT, ROI, הבעיה והפתרון).
- **Session 2** = ההצעה ללקוח (להוסיף כרטיס BlueField-3 ל-9800).

מונחים טכניים מוכרים נשארים באנגלית גם בדיבור - ליד כל אחד יש איך לומר/להסביר בעברית.

## 1. שיווק, עסקים וכסף

| מונח (English) | עברית | מה זה בקצרה |
|---|---|---|
| TCO - Total Cost of Ownership | עלות בעלות כוללת | כמה המוצר באמת עולה ל-3 שנים: חומרה + רישיונות + תמיכה + מנויים, לא רק מחיר הקופסה |
| ROI - Return on Investment | החזר על ההשקעה | כמה מרוויחים ביחס למה שהשקענו (ב-Session 1: 269%) |
| CAGR | שיעור צמיחה שנתי ממוצע | קצב הגדילה של שוק/הכנסה בשנה, בממוצע |
| TAM | שוק פוטנציאלי כולל | גודל כל השוק שאפשר למכור אליו |
| Market Share | נתח שוק | איזה אחוז מהשוק הספק מחזיק (לא בהכרח = הכי טוב) |
| ASP - Average Selling Price | מחיר מכירה ממוצע | ערך עסקה ממוצע (בעלייה של +15K לעסקה עם המודול) |
| Win-rate | אחוז זכייה | כמה מהעסקאות אנחנו מנצחים (יעד +10 נקודות) |
| Customer Retention | שימור לקוחות | כמה לקוחות נשארים/מחדשים (יעד +5 נקודות) |
| Installed Base | בסיס מותקן | הלקוחות שכבר קנו ומריצים את המוצר |
| Attach Rate | שיעור צירוף | כמה מהעסקאות החדשות כוללות גם את המודול/תוספת |
| Renewal Window | חלון חידוש | התקופה שבה הלקוח מחליט אם לחדש - הרגע למכור שדרוג |
| Break-even | נקודת איזון | מתי ההכנסות מכסות את ההשקעה (חודש 16 מ-GA) |
| Gross Margin / Gross Profit | רווח גולמי / שיעור רווח גולמי | מה נשאר אחרי עלות הייצור הישירה (65% על המודול) |
| CapEx / OpEx | הוצאה הונית / הוצאה שוטפת | רכישת ציוד חד-פעמית מול עלות תפעול מתמשכת |
| NRE - Non-Recurring Engineering | עלות פיתוח חד-פעמית | כסף חד-פעמי לפיתוח (למשל תכנון שבב) |
| SKU | מק"ט / פריט קטלוגי | מוצר מוגדר שאפשר להזמין ולתמחר |
| GTM - Go-to-Market | אסטרטגיית יציאה לשוק | איך מוכרים, מתמחרים ומשווקים את המוצר |
| Value Proposition | הצעת ערך | ההבטחה ללקוח במשפט אחד |
| Differentiator | בידול / יתרון מבדל | מה שמייחד אותנו מול המתחרים |
| Vendor Lock-in | נעילה לספק | תלות שקשה לצאת ממנה (ASIC צרוב = נעילה; כרטיס = לא) |
| Forklift (upgrade) | החלפת מערכת / "מלגזה" | החלפה מלאה של הקופסה - יקר, עם מיגרציה וחלון תחזוקה |
| Over-provision | רכישת-יתר | לקנות יותר חומרה ממה שצריך "ליתר ביטחון", שיושבת בטלה |
| Headroom | מרווח נשימה | כמה קיבולת פנויה נשארה עד התקרה |
| Ceiling | תקרה | הגבול המקסימלי של ביצועים (10G TP+TLS ל-9800) |
| Blind Spot | נקודה עיוורת | תעבורה שלא נבדקת - שם מסתתרות התקפות |
| PoC / Proof of Value | הוכחת היתכנות / הוכחת ערך | פיילוט קצר שמוכיח את הטענה לפני התחייבות מלאה |
| Design Partner | שותף עיצוב | לקוח שמקבל חומרה מוקדם ומשפיע על הדרישות |
| GA - General Availability | זמינות כללית | הרגע שהמוצר משוחרר לכלל הלקוחות |
| Beta | גרסת בטא | שלב ניסוי מתקדם לפני GA |
| Roadmap | מפת דרכים | תוכנית הגרסאות והיכולות העתידיות |
| Gartner Magic Quadrant (MQ) | ריבוע הקסם של גרטנר | דירוג ספקים לפי "חזון" מול "יכולת ביצוע" |
| Leader / Challenger / Visionary / Niche | מוביל / מאתגר / חזונאי / נישה | ארבעת הריבועים ב-MQ (Check Point = Leader) |
| CISO | מנהל אבטחת מידע ראשי | מקבל ההחלטות אצל הלקוח (קהל היעד של Session 2) |
| RFP | בקשה להצעות מחיר | מסמך דרישות שהלקוח מפרסם לספקים |

## 2. סייבר ואבטחה

| מונח (English) | עברית | מה זה בקצרה |
|---|---|---|
| Firewall | חומת אש / פיירוול | שומר הסף של הרשת - מחליט מה נכנס ומה נחסם |
| NGFW - Next-Generation Firewall | פיירוול דור הבא | פיירוול + זיהוי אפליקציות + IPS בסיסי |
| Security Gateway | שער אבטחה | ה-appliance שמריץ את כל מנועי ההגנה |
| Threat Prevention (TP) | מניעת איומים | כל מנועי ההגנה יחד (IPS, AV, Anti-Bot) פועלים במקביל |
| Throughput | תפוקה | כמה גיגה-ביט בשנייה עוברים דרך הקופסה |
| TLS / SSL Inspection | בדיקת תעבורה מוצפנת | פתיחת HTTPS לבדיקה והצפנה מחדש - בלי זה הפיירוול עיוור |
| Decrypt / Re-encrypt | פענוח / הצפנה מחדש | פותחים את ההצפנה לבדיקה ואז סוגרים אותה שוב |
| IPS - Intrusion Prevention System | מערכת מניעת חדירות | מזהה וחוסם חתימות התקפה ידועות (exploit, CVE) |
| AV - Antivirus | אנטי-וירוס | סורק קבצים נכנסים לאיתור נוזקה |
| Anti-Bot | אנטי-בוט | מזהה תקשורת של מחשב נגוע עם התוקף (C2) |
| Application Control | בקרת אפליקציות | מזהה ומגביל אילו אפליקציות רצות (TikTok/Telegram) |
| URL Filtering | סינון כתובות | חוסם אתרי פישינג וקטגוריות אסורות |
| Threat Emulation / Sandbox | הדמיית איומים / ארגז חול | מריץ קובץ חשוד בסביבה מבודדת לראות אם הוא זדוני |
| DLP - Data Loss Prevention | מניעת דליפת מידע | מונע הוצאת מידע רגיש מהארגון |
| Zero-day | פרצת יום-אפס | התקפה חדשה שאין לה עדיין חתימה מוכרת |
| Malware | נוזקה | תוכנה זדונית |
| Phishing | דיוג / פישינג | התחזות כדי לגנוב פרטים או גישה |
| Exploit / CVE | ניצול פרצה / מזהה פרצה רשמי | שימוש בחולשה ידועה בתוכנה |
| C2 - Command and Control | שרת שליטה ובקרה | השרת שממנו התוקף שולט במחשב הנגוע |
| Data Exfiltration | גניבת/הוצאת מידע | הברחת מידע החוצה מהארגון |
| Signature / Pattern | חתימה / תבנית | "טביעת אצבע" של התקפה ידועה שה-IPS מחפש |
| Behavioral analysis / ML inference | ניתוח התנהגותי / הסקה בלמידת מכונה | זיהוי איום חדש לפי התנהגות, לא לפי חתימה |
| Inline | בנתיב / בזרימה | ההגנה חוסמת תוך כדי המעבר, לא מתריעה בדיעבד |
| Prevention-first | מניעה תחילה | לחסום את ההתקפה, לא רק להתריע עליה |
| ThreatCloud AI | ענן האיומים של Check Point | מודיעין איומים משותף שמזין את כל המנועים |
| Post-Quantum Cryptography | הצפנה עמידה לקוונטום | הצפנה חדשה שתעמוד מול מחשבים קוונטיים |
| Air-gapped | מנותק רשת / פער אוויר | סביבה מבודדת פיזית מהאינטרנט |
| Span Port / Mirror / Monitor mode | פורט שיקוף / מצב ניטור | העתק של התעבורה לבדיקה בלי להיות בנתיב (ללא סיכון) |

## 3. ארכיטקטורה, חומרה וביצועים

| מונח (English) | עברית | מה זה בקצרה |
|---|---|---|
| L3/L4 (Layer 3/4) | שכבה 3/4 | סינון לפי כתובת IP ופורט - רק "המעטפה", לא התוכן |
| L7 (Layer 7) | שכבה 7 | רמת האפליקציה - מזהה אתר, אפליקציה ומשתמש |
| DPI - Deep Packet Inspection | בדיקת מנות לעומק | פתיחת התוכן עצמו של התעבורה, לא רק הכותרת |
| Packet / IMIX | מנה / תמהיל מנות אמיתי | יחידת תעבורה; IMIX = ערבוב גדלים כמו בעולם האמיתי |
| Latency (μs) | השהיה (מיקרו-שניות) | כמה זמן הקופסה מוסיפה לכל מנה (9800 = 1.85μs) |
| New Connections/sec | חיבורים חדשים בשנייה | כמה חיבורי TCP חדשים נפתחים בשנייה |
| Concurrent Sessions | חיבורים בו-זמנית | כמה חיבורים פתוחים נשמרים בזיכרון במקביל |
| State Table | טבלת מצב | הזיכרון שמנהל את כל החיבורים הפעילים |
| ASIC | שבב ייעודי | חומרה שתוכנתה למשימה אחת - מהיר אבל "צרוב", קשה לשנות |
| FPGA | שבב בר-תכנות | חומרה שאפשר לתכנת מחדש, אך דורש עבודת HDL לכל מנוע |
| DPU - Data Processing Unit | יחידת עיבוד נתונים | הכרטיס החכם (BlueField-3) שמוריד עומס מה-CPU |
| BlueField-3 | כרטיס ה-DPU של NVIDIA | הכרטיס שמוסיפים ל-9800; מריץ TLS+IPS על סיליקון ייעודי |
| NIC / SmartNIC / ConnectX | כרטיס רשת / כרטיס רשת חכם | מעביר תעבורה; ConnectX מאיץ רק TLS, בלי ליבות לריצת IPS |
| SPU (NP7 / CP9) | מעבדי האבטחה של Fortinet | שבבים ייעודיים של פורטינט ל-L3/4 ולתוכן |
| Offload / Hardware Acceleration | הורדת עומס / האצת חומרה | להעביר עבודה כבדה מה-CPU לחומרה ייעודית |
| x86 / Xeon / EPYC | מעבד כללי (אינטל/AMD) | ה-CPU הרגיל - גמיש אבל צוואר בקבוק ל-TLS |
| Arm cores | ליבות Arm | מעבדים שעל ה-DPU, מאפשרים להריץ IPS/AI על הכרטיס |
| PCIe Gen5 | ממשק כרטיסים מהיר | התקן החיבור של הכרטיס ללוח |
| DMA (zero-copy) | גישה ישירה לזיכרון | העברת נתונים מהירה בלי להעתיק, לשמירת ההשהיה |
| DOCA SDK | ערכת הפיתוח של BlueField | התוכנה לפתח על ה-DPU |
| RXP | מנוע/מהדר חתימות regex | ממיר את מאגר ה-IPS לפורמט שהחומרה מריצה |
| CoreXL | מנוע ריבוי-ליבות של Check Point | מחלק עבודה בין ליבות ה-CPU |
| Form Factor / RU - Rack Unit | גודל פיזי / יחידת מסד | גובה הקופסה במסד (1RU = ~4.5 ס"מ); 9800 = 1RU |
| Gbps | גיגה-ביט בשנייה | יחידת מדידת תפוקה |
| HA - High Availability | זמינות גבוהה | זוג קופסאות, אחת פעילה ואחת בכוננות |
| Active / Standby / Failover | פעיל / כוננות / מעבר גיבוי | כשקופסה נופלת, השנייה לוקחת את כל העומס |
| ClusterXL | אשכול HA של Check Point | מנגנון הזוג והסנכרון בין הקופסאות |
| Maestro | הרחבה/אשכול בקנה מידה | חיבור כמה קופסאות להגדלת קיבולת (×4 = 4 קופסאות) |

## 4. תקינה, רגולציה ומוצרי פלטפורמה
