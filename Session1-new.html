ההנחות מאחורי המספרים
  1. גודל שוק: $13.8B (2026) → ~$20B (2030), CAGR 9.6% (MarkWide / Gartner). $ סגמנט = נתח × גודל שוק.
  2. מיפוי סגמנטים (לא קיימים אצל האנליסטים): Branch ≈ SMEs + branches; HQ ≈ campus edge; DC ≈ high-end appliances; Regulated ≈ BFSI + Gov + Health; OT ≈ industrial / trading; Cloud ≈ virtual FW + FWaaS.
  3. Branch ~13%: SMEs ≈ 31% מ-NGFW, צומחים 16% (Mordor 2025); הנחנו פחות — חלק זולג ל-managed / SASE.
  4. HQ ~6%: SASE מחליף appliances בקצה הקמפוס (Fortinet SASE billings +40%). מתחת לשוק → נתח יורד.
  5. DC ~11%: hardware עדיין 54%; Gartner +$9.9B HW עד 2030; AI east-west traffic. נתח יציב, $ גדל.
  6. Regulated ~10%: BFSI צומח 15.7%, Zero Trust DoD 2027, NIS2 — מול זליגה ל-virtual / sovereign cloud. נטו ≈ שוק.
  7. Cloud ~18%: virtual/cloud FW +15.1%, hybrid cloud +16.2% (Mordor). SASE כשוק לא נכלל — רק ה-firewall שבתוכו. OT ~12%: IT/OT + NIS2; קטן אבסולוטית.
  8. הכנסות vendor: Σ(נתח בסגמנט × גודל סגמנט) — מתכנס ל-IDC היום. 2030 = אפקט mix + המשך drift 2020→26 של IDC: CP −0.2 נק'/שנה, PA +0.75, Cisco −0.7, Fortinet +0.8 (ממותן מ-1.3). לא כולל M&A, מיתון, tariffs. ±3 נק' סבירות.
